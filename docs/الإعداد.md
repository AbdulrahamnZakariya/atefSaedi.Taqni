# إعداد الموقع الآمن والوكيل

البنية: المستودع (خاص) هو التخزين الخاص ← Cloudflare Pages + Functions هو الخادم ← Cloudflare Access هو تسجيل الدخول (كود على الإيميل).
الخادم بيتحقق من الدخول بنفسه كمان، فلو Access انضبط غلط ما بينفتح إشي. التكلفة: $0 (ضمن المجاني لشخصين).

## 1. توكن GitHub (دقيقتين)
github.com/settings/personal-access-tokens ← Generate new token (Fine-grained):
- Repository access: Only select repositories ← `atefSaedi.Taqni`
- Permissions ← Contents: **Read and write**
- انسخ التوكن.

## 2. مشروع Cloudflare Pages (5 دقايق)
dash.cloudflare.com ← Workers & Pages ← Create ← تبويب **Pages** ← Connect to Git ← اختار `atefSaedi.Taqni`:
- Production branch: `main`
- Framework preset: None
- Build command: `python3 tools/build-site.py`
- Build output directory: `site`
- Save and Deploy. (أول نشر بيعطي «تسجيل الدخول مطلوب» وهذا طبيعي.)

بعدها: المشروع ← Settings ← Build ← Build watch paths ← Include: `index.html`, `assets/*`, `functions/*`, `tools/*`
(عشان ما يعيد النشر مع كل تحديث قوائم أو مهام.)

## 3. تسجيل الدخول: Cloudflare Access (5 دقايق)
dash.cloudflare.com ← Zero Trust (أول مرة: اختار اسم فريق، والخطة Free، ما في دفع).
1. Settings ← Custom Pages/General: انسخ **Team domain** (مثل `kayanat.cloudflareaccess.com`).
2. Access ← Applications ← Add an application ← **Self-hosted**:
   - Application domain: `اسم-مشروعك.pages.dev`، وضيف سطر ثاني: `*.اسم-مشروعك.pages.dev`
   - Policy: Action = Allow ← Include ← Emails ← إيميلك وإيميل أبو أنفال
   - Login methods: One-time PIN
   - Save. افتح التطبيق وانسخ **Application Audience (AUD) Tag**.

## 4. متغيرات الخادم
مشروع Pages ← Settings ← Variables and Secrets ← Add (Production، والنوع **Secret** لكل وحدة):

| الاسم | القيمة |
|---|---|
| `GITHUB_TOKEN` | التوكن من الخطوة 1 |
| `REPO` | `abdulrahamnzakariya/atefSaedi.Taqni` |
| `GEMINI_API_KEY` | مفتاح Gemini |
| `SIGNING_KEY` | نص عشوائي طويل (32 حرف أو أكثر) |
| `PRIV_PASSWORD` | كلمة سر الملف الخاص (**جديدة**: القديمة بصمتها كانت منشورة) |
| `ALLOWED_EMAILS` | `إيميلك,إيميل-أبو-أنفال` |
| `OWNER_EMAIL` | إيميل أبو أنفال |
| `ACCESS_TEAM_DOMAIN` | Team domain من الخطوة 3 (بدون https) |
| `ACCESS_AUD` | AUD Tag من الخطوة 3 |
| `GEMINI_MODEL_FAST` | (اختياري) اسم موديل Flash، الافتراضي `gemini-3.5-flash` |
| `GEMINI_MODEL_PRO` | (اختياري) موديل العمليات، الافتراضي `gemini-3.1-pro-preview` (إذا مش متاح بيرجع لـ Flash لحاله) |
| `VIEWER_EMAILS` | (اختياري) إيميلات زوار للأسئلة فقط، بدون أدوات تعديل |

بعدها: Deployments ← آخر نشر ← Retry deployment.

## 5. رابط التنبيهات
GitHub ← المستودع ← Settings ← Secrets and variables ← Actions ← تبويب **Variables** ← New:
`SITE_URL` = `https://اسم-مشروعك.pages.dev/`

## 6. التجربة
افتح الرابط من جوالك ← بيطلب إيميل ← كود ← بتدخل. جرّب صك، والملف الخاص بكلمة السر الجديدة، والمساعد.

## 7. قفل الرابط القديم (بعد ما تتأكد إن 6 تمام)
GitHub ← Settings ← General ← Danger Zone ← Change visibility ← **Private**.
GitHub Pages القديم بيوقف لحاله، وروابط الصكوك القديمة ما بتفتح.

## للتجربة على جهازك (اختياري)
ملف `.dev.vars` بجذر المستودع (مستثنى من git) فيه نفس المتغيرات، وزيادة `DEV_AUTH_EMAIL=إيميلك` (بيشتغل على localhost بس)، وبعدها:
`python3 tools/build-site.py && npx wrangler pages dev site`

## الإدخال التلقائي (ingest.py)
ما تغيّر إشي: بيكتب `index.html` والملفات بالمستودع زي قبل، والموقع الآمن بيقرأ منهم.
